# Devin

Demos and experiments.

- [**Devin Oncall Simulator**](oncall-simulator/) — a self-contained demo of an agentic on-call first responder: master triage agent, parallel child investigators, real PRs against a mock repo, and a self-improving playbook. `cd oncall-simulator && npm install && npm run demo`.
- [**Home Ops**](home-ops/) — Home Operations & Emergency Command Center: a React 19 + Supabase PWA for homeowners (appliance ledger, document vault, seasonal maintenance, emergency triage). `cd home-ops && npm install && npm run dev`.
